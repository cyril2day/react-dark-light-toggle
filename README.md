# Dark/Light Mode Portfolio

A single-page developer portfolio for "Simba" that showcases React mastery through a dark/light theme toggle with persistence, a filterable project gallery, a testimonial carousel, and a fully responsive layout.

**Live Site:** [https://cyril2day.github.io/react-dark-light-toggle/](https://cyril2day.github.io/react-dark-light-toggle/)

## Tech Stack

React 19, Vite 8, Tailwind CSS v4, lucide-react, react-icons, oxlint, pnpm — deployed to GitHub Pages.

## React Features

Theme management via the **Context API** and a custom `useTheme()` hook, `useState`-driven filters and carousels, and component composition with StrictMode.
